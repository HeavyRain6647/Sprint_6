# Автоматизация UI-тестирования (Sprint 6)

Проект посвящен углубленной работе с Selenium WebDriver и написанию стабильных UI-тестов.

### Основные навыки:
* Использование **WebDriverWait** (явные ожидания) для работы с динамическими элементами.
* Поиск элементов через сложные **XPath** и **CSS-селекторы**.
* Организация структуры независимых тестов на фреймворке Pytest.
