# Автоматизация UI-тестирования сервиса Stellar Burgers (Sprint 6)

Проект по автоматизации пользовательского интерфейса (UI) популярного сервиса заказа бургеров. Основная цель — проверка ключевых пользовательских путей и навигации.

## 🛠 Технологии и инструменты
* **Язык:** Python 3.x
* **Тест-фреймворк:** Pytest
* **Инструмент автоматизации:** Selenium WebDriver
* **Архитектура:** Page Object Model (POM)

## 🧪 Что протестировано в проекте:

### 1. Регистрация пользователя (`test_registration.py`):
* Успешная регистрация с валидными данными.
* Проверка валидации поля «Пароль» (минимальная длина 6 символов).

### 2. Вход в аккаунт (`test_login.py`):
* Вход через кнопку «Войти в аккаунт» на главной странице.
* Вход через кнопку «Личный кабинет».
* Вход через форму регистрации и форму восстановления пароля.

### 3. Личный кабинет и навигация (`test_personal_account.py`):
* Переход в личный кабинет авторизованным пользователем.
* Переход из личного кабинета в «Конструктор» и по клику на логотип Stellar Burgers.
* Выход из аккаунта (Logout).

### 4. Конструктор (`test_constructor.py`):
* Проверка работы переключателей в конструкторе («Булки», «Соусы», «Начинки»).
* Визуальное подтверждение активации выбранного раздела.

## 📂 Структура проекта
* `locators/` — централизованное хранение локаторов элементов.
* `pages/` — объектно-ориентированное описание страниц и методов взаимодействия.
* `tests/` — тестовые сценарии, разделенные по функциональным блокам.

## 🚀 Как запустить
1. Установите зависимости: `pip install selenium pytest`
2. Запустите тесты: `pytest`
